# HuaweiStickManager

תוסף כרום לניטור, ניהול וקבלת התראות חכמות ממודם/סטיק סלולרי של **Huawei** (חיבור ישיר לממשק המקומי, ללא צורך להשאיר את דף הניהול של הסטיק פתוח).

---

## יכולות עיקריות

- **דאשבורד בזמן אמת:**
  - תצוגת אחוז סוללה ומצב טעינה.
  - עוצמת קליטה, דור הרשת (`2G` / `3G` / `4G LTE` / `LTE-A` / `5G`) ושם מפעילת הסלולר.
  - מעקב אחר חבילת הגלישה החודשית, נפח הורדה/העלאה וזמן חיבור, כולל חישוב **קצב צריכה יומי** מול יום חידוש החבילה.
- **ניטור והתראות רקע אוטומטיות:**
  - בדיקות מחזוריות ברקע (תדירות ניתנת להגדרה לכל דקה / 3 / 5 / 10 דקות), כולל השלמת בדיקה אוטומטית בחזרה ממצב שינה.
  - **התראת סוללה נמוכה:** שליחת התראת מערכת קלילה הנעלמת למרכז ההתראות אחרי כ-10–15 שניות ונמחקת ממנו אחרי 5 דקות.
  - **מצב חירום (סוללה קריטית):** הפעלה לבחירה של כרטיסייה ייעודית, חלון צף, התראת צליל ו/או באנר עליון בדף הפעיל, בנוסף להתראת מערכת.
  - **תגית (Badge) על סמל התוסף:** התראה מיידית על הודעות SMS שלא נקראו, סוללה נמוכה או חריגת גלישה.
  - **מעקב התקנים:** התראות על חיבור וניתוק של מכשירים מהרשת האלחוטית של הסטיק.
- **ניהול SMS והתקנים:**
  - קריאת הודעות SMS נכנסות, סימון כנקרא ומחיקה ישירות מהתוסף.
  - הצגת דגם הסטיק, הפעלת צימוד **WPS** לשתי דקות, כיבוי הסטיק, שינוי סיסמת Wi-Fi ושמירת היסטוריית התקנים עם שמות מותאמים.
- **ממשק גמיש וגיבוי:**
  - פתיחה כחלונית קופצת (Popup), פאנל צד (Side Panel) או כרטיסייה מלאה.
  - יצוא ויבוא מלא של ההגדרות והיסטוריית ההתקנים לקובץ JSON.
  - בדיקת עדכונים אוטומטית מול GitHub Releases.

---

## התקנה (טעינה מקומית בכרום)

1. הורידו את הגרסה העדכנית (`HuaweiStickManager.zip`) מדף ה-[Releases](https://github.com/Tzadikvtovlo/HuaweiStickManager/releases/latest) וחלצו לתיקייה קבועה במחשב.
2. פתחו בכרום את הכתובת `chrome://extensions/`.
3. הפעילו **מצב מפתח (Developer mode)** בצד העליון.
4. לחצו על **טעינת פריט לא ארוז (Load unpacked)** ובחרו את התיקייה שחולצה.

---

## הגדרה ראשונית

1. פתחו את התוסף ועברו ללשונית **הגדרות**.
2. הזינו את כתובת ה-IP של הסטיק (ברירת מחדל: `192.168.8.1`), שם המשתמש (`admin`) וסיסמת הניהול של הסטיק, ולחצו **שמור הגדרות**.
3. ניתן ללחוץ **בדוק** לאימות החיבור, וכן **משוך נתונים** לשאיבת פרטי חבילת הגלישה ישירות מהסטיק.
4. לבדיקה ידנית של מנגנון ההתראות בכל רגע: לחיצה ימנית על סמל התוסף ← **בדוק התראות (טסט ידני)**.
